# Grade Planner — INSY 2299

Interactive grade planner for INSY 2299 (Information Systems). Students enter the scores they already have from Blackboard and project their course grade under different scenarios for the outstanding work.

Live page: https://dom-mol.github.io/Grade-Planner-INSY2299/

Entries are saved only in the student's own browser; nothing is sent anywhere. The projection is an estimate — the official grade is the one posted by the instructor.
